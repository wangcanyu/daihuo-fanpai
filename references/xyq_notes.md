# 小云雀(xyq)后端使用笔记 — 与即梦的关键区别

> 来源:《产品手册·小云雀Web》(飞书wiki, 2026-07-09版, 07-17抓取) + pippit-tool-cli --help 实测。
> 全文存档: xyq_web_manual.txt(同目录)。CLI侧计费/参数官方文档暂缺,以下标注"待实测"的以首跑为准。

## 1. 小云雀是什么(对本 skill 而言)

字节旗下 AI 创作平台(xiaoyunque.jianying.com),两条路径:
- **后端 Agent 编排**:自然语言需求→后端 Agent 自主规划工作流(Agent模式/短剧Agent/一镜到底/爆款复刻)。CLI 里对应 xyq-skill 的 submit_run.py 会话路由。
- **模型直出**:即"沉浸式短片"的直出档。`pippit-tool-cli generate-video/generate-image` 走的就是这条,xyq_gen.py 包装的也是它。

## 2. 与即梦 CLI 的核心区别(写提示词前必读)

| 维度 | 即梦 dreamina CLI | 小云雀 generate-video |
|---|---|---|
| 声音范式 | **上传 wav 音频驱动口型**(multimodal2video --audio) | **台词写进 prompt,模型自己生成语音**(Seedance 2.0 原生音画);--audio 是"参考音频",具体角色(BGM参考?口型驱动?)**待实测** |
| 提示词公式 | @图片1/@音频1 素材指代 + 台词{}约定 | 官方黄金公式: [主体描述]+[画面运动]+[音效互动]+[台词]+[音色描述]+[运镜/环境]+[风格修饰]+[限定信息] |
| 音效 | 无(后期加) | **prompt 里写音效互动**(开袋声/咀嚼声),模型直接生成 |
| 模型 | seedance2.0_vip(积分池) | Seedance_2.0_mini_lite(普通户默认) / seedance2.0_vision·fast_vision·Seedance_2.0_mini(VIP);XYQ_VIDEO_MODEL 覆盖 |
| 计费 | 5500/月积分池 | 独立 credits 池,**单价规则文档未见,待实测** |
| 参考素材上限 | 多模态≤9图 | --image ≤9、--video ≤3、--audio ≤3 |
| 首尾帧 | 无显式参数 | `--generate-type 1` + 两次 --image(首帧、尾帧顺序) |

**对本管线的直接影响**:
- **mm 口播段仍走即梦**:我们的口播=CosyVoice 精确台词+固定音色,即梦音频驱动口型能逐字对上;小云雀模型自生语音,音色不可精确复现→跨段音色漂移,除非实测证明 --audio 能驱动口型。
- **i2v 段(hero/包装)小云雀可直接用**:真产品图 + 轻运镜提示词,范式与即梦 image2video 相同。写 prompt 时可额外补一句音效描述(小云雀会生成环境音,即梦不会——装配时若配了 TTS 旁白注意别撞声,必要时 prompt 写"无人声")。
- 沉浸式短片支持**视频链接参考/图片+视频混合参考**(Web端);CLI 的 --video 参考对应此能力,复刻运镜时可传原片段作参考(**待实测**)。

## 3. 值得知道的 Web 端功能(不走 CLI,人工备用)

- **爆款复刻**:Web 一键复刻(文案结构/剧情框架/配乐画风),输入抖音/头条/西瓜链接或本地上传。与本 skill 同赛道——**定位=快速粗仿对照组**:无人审闸口、无产品锚图纪律、台词不可精确控制,不能替代本管线的 B 模式;但接新单前可先用它 5 分钟出个草样感受难度。
- **一镜到底**:2-10 张图→自动补转场出连贯长镜头(可写转场描述)。产品多形态串联展示镜(礼盒→内包装→单根)可考虑用它出素材。
- **短剧 Agent**:剧本(≤10万字 txt/docx)→全自动角色/场景/分集出片。归 xyq-short-drama-skill 管,与本 skill 无关。
- 生图模型:Web=Seedream 5.0 Lite + 4.0 美感版;CLI=seedream_5.0_pro(支持1K/2K/4K)/5.0/4.5/4.3/4.1/4/nova2。人物锚定图/产品图补图可用。

## 4. 实测记录(2026-07-17 首跑,高小参内包装 5s/720p/9:16/mini_lite)

1. [x] **i2v 语义=参考重绘,非首帧锚定**(判决书):构图/光影/运镜/袋内海参质感全优,但包装被重绘——袋形从平铺变立起,大字"鲜食海参"勉强存活,"高小参"品牌字被绘错,599价签/开袋即食/净含量/英文**全部乱码**。对比即梦 image2video 同图"高小参/599"全程清晰。**结论:mini_lite 档不能接有品牌文字的包装镜,只能接无文字要求的氛围/质感镜**。VIP 档(seedance2.0_vision)是否锚得住待测。
2. [x] **「AI生成」水印烧死在左上角**(mini_lite 档)——投放素材硬伤;VIP 档是否有水印待测。
3. [x] 端到端链路通:submit→xyq_link→轮询→下载 6.5MB 全自动;**model 为服务端必填**(CLI 无默认,漏传 ret=2),xyq_gen 已默认 Seedance_2.0_mini_lite。
4. [x] 输出核对:web_thread_link/thread_id/run_id 解析正常;产物带 AAC 音轨(自生音频实锤,assemble 会覆盖不冲突)。
5. [x] **credits 消耗:5s/720p/mini_lite = 20积分**(用户Web端实查,2026-07-17)。CLI 回执不报消耗,记账去 Web 端。参考换算:即梦 image2video 同规格约70积分/段(池子不同不直接可比,但小云雀单段名义数字更小)。
6. [ ] --audio 参考音频的实际角色(若能驱动口型→mm 段解锁第二供应商)
7. [ ] --video 参考(传原片段复刻运镜)是否 CLI 可用
8. [~] VIP 档 vision 模型:**账号=基础会员,VIP 测试搁置**。若日后升级再测文字锚定/去水印,在那之前 mini_lite 定位(无文字氛围镜)即最终定位。

## 5. 当前分工定位(按首跑结论)

- **即梦**:口播口型 + 一切带品牌文字的包装/产品镜(首帧锚定,文字保真唯一解)
- **火山Ark**:无人脸的 i2v 卸载(token 计费省积分)
- **小云雀 mini_lite**:仅接"无文字要求"的氛围镜/空镜/质感辅助镜,且左上角有 AI生成 水印(剪映可裁/遮,或仅用于草样预览);升 VIP 后重测再提级
