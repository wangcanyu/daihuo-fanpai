# E 模式：人设号复刻（画布流，11-09 定型）

**用途**：用固定的 AI 人设（比如 IG 健康号的 Grandma Mei）逐条复刻别人的爆款，整条都换成自己人设出镜。
**和 A 模式的区别**：A 是"反推、规划、TTS、装配"的自动管线。E 是每一步都**和原片并排对比、让人确认后**再往下走的手工流程。
**实证**：Grandma Mei 第 2、3 条。第 3 条小面包原片 12 镜，我们分 4 段生成，每段只跑 1 次，一共 49 秒视频积分，用户看完说"整体没啥问题，越来越好了"。
第 1 条走的是老办法：文字描述首帧，每段单独生成，重跑了很多次，先后出了 A～H 共 8 版。第 3 条每段只跑 1 次就成片。

手动在 LibTV、RunningHub 画布上复现，或者教别人，看 `画布手动流程.md`。本文件是给 agent 用的版本，带脚本。

---

## 为什么比老办法好：四个关键改动

| 老办法的病 | E 模式的解法 |
|---|---|
| 首帧用文字凭空描述：离得远、主体小、动作没开始，不如原片抓人 | **首帧照原片构图**：原片对应帧涂掉脸和字幕，和人设图、场景图、道具图一起喂生图模型，"照参考 1 构图，换人换景" |
| 硬切后道具变样：搅拌机把手消失、鱼缸忽大忽小 | **先做道具资产图**，再挂进视频参考；同一道具的不同状态从同一张图改出来（生坯→成品→掰开） |
| 同场景下一段首帧重新画，道具大小、位置对不上 | **下一段首帧直接用上一段的真实末帧**，连生图都省了 |
| 一镜一生成，镜头多、积分多，运镜和切镜都丢了 | **一条生成里写多镜头**（镜头一/硬切/镜头二），按原片节奏分段，有因果的动作放在同一条里 |

## 流程（每步后面是用户确认点 ☑）

### 0. 选原片
从对标库挑高播放的。优先镜头少、场景少、道具少的，日更做得过来。
最好同一个账号不要连着用太多条，第 4 条就该换号了。

### 1. 拆原片
用 `seed_reverse.py` 的 shotlist 或已有反推结果，列出每个镜头的时间、景别、机位、动作、台词。
截每个镜头的首帧拼一张总览图，给用户和自己对着看。

### 2. 台词 ☑
- **保留原片句子和语气，不要改温和**。用户 11-08 批评过："你改得太过于温和了，尽量保留原版。"
- **只换两类**：阴谋论（大药厂不让你知道…），具体到病的治疗功效（消炎、排肝毒、降胆固醇）。
- 原片的冲击句一律保留，比如 "won't spike your blood sugar"、"hits your insides like a reset button"。
- 时长估算：英文词数 ÷ 2.6 + 0.5 秒（奶奶语速）。成片会比原片长一些，最后整片 1.1 倍速拉回来。

### 3. 分段
按原片节奏切成 4 段左右，每段 1～3 个硬切。三条原则：
- 同一场景、同一动作链的镜头放在同一段。
- 有因果的必须放在同一段：倒进去和浮上来、掰开和露出内芯。
- 无脸特写（手部操作）可以单成一段走画外音，首帧用上一段的末帧。
小面包的分法：S1 镜 1–4（6 秒）、S2 镜 5–7（8 秒，纯手，画外音）、S3 镜 8–10（13 秒）、S4 镜 11–12（22 秒）。

### 4. 资产 ☑
- **人设**：一张定版正脸，加一张四视图（1 个真脸格 + 3 个无头全身）。模型改图会顺手重画脸，改完要把真脸贴回去。
- **场景**：定版场景。原片里有、我们场景里没有的东西要补，比如烤箱角落，用场景图改出来。
- **道具**：每个反复出现的道具一张图，写明识别点（把手在哪边、几个、排列）。同一道具的不同状态用 General image V2.1 从上一张改出来，保证是同一个盘、同样的排列。
- **音色参考**：一段干净人声，只当音色用。

### 5. 首帧 ☑（最关键）
```bash
python3 renshe/mask_frame.py 原片.mp4 10.2 mask_8.jpg 240,110,600,640 150,640,420,730   # 涂掉脸和字幕
libtv upload V3原片8去脸 -f mask_8.jpg                                                    # 节点名要唯一，传完用 node list 核实
bash renshe/libtv_img.sh jobs_kf.json 0 out_kf                                            # Lib Image 2.5 Pro，出 1 张
python3 renshe/side_by_side.py 首帧对比.jpg mask前原帧.jpg out_kf/xxx.png ...              # 并排发给用户
```
首帧提示词模板（英文）：
```
Recreate the exact composition, camera distance, angle and framing of {{Node "原片去脸"}}: <一句话描述原片画面：拿什么、占画面多大、动作到哪一步>.
The <道具> look exactly like {{Node "道具图"}}.
Replace the person with the woman in {{Node "人设定版"}}: same face, <眼镜/发型/口红/衣服/首饰>. Her face is <在画面哪里>, looking <看哪>, <表情>.
Replace the room with the tea shop of {{Node "场景图"}}, softly blurred.
The grey rectangles in the reference are only placeholders, do not draw them. No text, no captions, no watermark. Real smartphone photo, natural daylight.
```
- 模型用 **Lib Image 2.5 Pro**（GPT Image 系）。General image V2.1 会把原片演员的手和手表带进来（11-08 实撞）。
- 参考最多 4 张：去脸原片、人设、场景（或带服装的旧定帧）、道具。
- **合规边界**：原片帧只提供构图，脸被涂掉了，人物长相只来自自己的人设图。这和"人物锚定图绝不从原片抽帧"的铁律不冲突。

### 6. 生成视频
```bash
bash renshe/libtv_vid.sh jobs_vid.json 0      # Seedance 2.5 / mixed2video / 9:16 / 720p / 有声 / 只跑 1 次
```
提示词写中文，英文台词用 `使用英语，奶奶说：{...}` 的格式；画外音段写 `她的画外声音`。模板和 4 段实例在 `prompts/示例_小面包/`。
写之前先用 `seedance-prompt` skill 的 lint 检查一遍：`lint_prompt.py f.txt --line 2.5`。审核词提醒先照原样交，被拒再改。
- 结构：【生成目标】【参考素材职责】【主体与关系】【事件脚本 镜头一/硬切/镜头二】【保持一致】。
- 参考素材职责里逐个写清用途：首帧"以它为准"，道具图"只用于外形"，音色"只用音色，不用它的台词"。
- 台词贴着动作和表情写，不要逐秒排动作，否则人会像提线木偶。
- 一条最长实测 22 秒（S4，2 个镜头、3 句台词，逐字对）。
- 同一场景的下一段：先截上一段末帧（`ffmpeg -ss <末尾前0.1s>`）上传成节点，再直接当首帧。
- 没有依赖关系的段并行跑，LibTV 实测 3 路并发正常。

### 7. 质检
```bash
python3 renshe/qc_seg.py vid/*.mp4     # qc/<段>.jpg 2fps 接触表 + ASR 逐句时间轴 + 切镜点
```
逐项看：
- 台词是否逐字。
- 动作和因果对不对。
- **切镜前后道具和人脸的大小**，这一项最容易漏。
- 道具有没有缺件。
- 句间空白超过 1 秒、画面又没动作的，记下来剪掉。

**我（agent）对方位、穿模、数量的判断不可靠**。拿不准的明说"请你确认"，不要说"已检查没问题"。

### 8. 后期（能补就不重跑）
| 问题 | 做法 |
|---|---|
| 说完话还空着（推烤箱后空 1.3 秒） | 拆两段 trim 后 concat |
| 原片这里是推镜 | `fps=30,scale=2160:3840,zoompan=z='1+0.15*on/230':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=1:s=720x1280:fps=30`。**必须先 fps=30**，否则 24fps 源出来的画面会变短 |
| 原片这里切了特写 / 有穿帮道具 | crop 放大裁掉 |
| 特写太短 | setpts 慢放到 0.65 倍 |
| 两句话之间停顿太长，画面又看不到嘴 | 把后一句音频提前（J-cut） |

装配用这条：
```bash
KEYS="本条关键词…" SPEED=1.1 POSY=240 python3 renshe/assemble_sub.py 成片.mp4 S1.mp4 S2.mp4 S3.mp4 S4.mp4
```
- 每段按语音尾 +0.3 秒裁，整片 1.1 倍速（音调不变），词级字幕。
- 字幕是原片风格：Arial 白字细描边，关键词用 Georgia 粗斜体放大。**放顶部 y=240**：中部会挡主体，1060 以下会被 IG 的用户名和文案盖住。
- ASR 把句中逗号识别成问号之类的错，在脚本的 `FIX` 表里补一行。

### 9. 交付和发布 ☑
- 成片放桌面和网盘，**原片也一起传**，方便用户对比着看。
- 用户经常不在电脑前，SendUserFile 也可能断网，网盘是兜底。
- 配文用英文：开头是原片钩子，接着写配方（**补具体用量和温度**），一句人设故事，结尾提问 + 评论 YES + 关注；话题 10～13 个；打开 AI 标签。

## 翻车清单（都真实发生过）
| 现象 | 原因 | 防法 |
|---|---|---|
| 切镜后鱼缸、杯子突然变大变小 | 下一段首帧是重新画的 | 用上一段真实末帧 |
| 特写里的东西和倒进去的对不上 | 起因和结果分在两条里生成 | 放同一条 |
| 人像木偶，嘴不动，声音像画外音 | 逐秒排动作，台词没贴着脸写 | 台词贴动作，多写表情 |
| 推近后脸被推出画面 | 提示词写了推近 | 写"固定机位不推近"，推镜交给后期 zoompan |
| 首帧没有原片抓人 | 文字凭空描述构图 | 照原片构图，先涂掉脸 |
| 首帧里出现原片演员的手和手表 | 用了 General V2.1 | 换 Lib Image 2.5 Pro，手也要检查 |
| 硬切后搅拌机变样、把手没了 | 没做道具图 | 开工先做道具图 |
| 改图后人脸变了 | 改图模型会重画整张 | 改完把真脸贴回去 |
| 运镜和切镜全没了，画面平 | 为了一致性把机位全写死了 | 一致性靠首帧接续，运镜照原片保留 |
| 背景冒出一排国旗 | 提示词写了"能看到小美国国旗"，模型放大处理 | 已经在场景图里的东西，提示词里不要再强调 |
| 手镯和串珠分在了两只手上 | 提示词写了"叠戴在左手腕"仍会漂 | 只拍手的镜头影响小，露脸的镜头重点检查 |
