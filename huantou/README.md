# D 模式·换头测试（千川实投）

> 11-01 从海参测试（10-27～11-01，五批 40 多条成片）收拢。跟 A/B/C 的区别：**不复刻整条**，只用 AI 做 5～15 秒开头，接号上已经跑过的老主体，上千川实投，用数据挑开头。
> 第一个被系统放量的开头：开头11 超市抢货（来自开头榜抢购家族 + 用户在素材库标的「要复刻」），11-01 三个主体同时放量到 1.93 万。

## 一句话流程

```
挑开头（三张榜 / 用户标的要复刻 / 号内爆款重制）→ 登记出处
 → 首帧（GPT Image 图生图，演职表锁真人脸）→ Seedance 2.5 720p 出开头（带复刻音参考）
 → open_post.py（1.1 倍速 + 字幕 + AI 小字 + 切点）→ 逐句回听
 → [可选] 改写主体（分轨 + 复刻音替换红线句）→ 配空镜
 → join_open.py（一个开头 × 多个主体）→ 成片集中放「上传千川_MMDD_第N批」→ 传网盘
 → 每天日报 → ledger/parse_daily.py → ledger/build_ledger.py → 开头台账.md
```

## 判定口径（10-31 从号内 466 条消耗≥300 元素材算出，换号要重算）

- 系统放不放量看**3 秒播放率**（与消耗秩相关 0.40）和平均观看时长（0.45），**跟点击率无关（0.05）**。
- 3 秒播放率：及格 ≥31%，优秀 ≥41%；43～50% 最好，≥50% 反而回落。
- 点击率甜区 2～4%；≥6% = 勾人点但不买（AI 开头常落在这里）。消耗 <100 元时的高点击率不算数（会被稀释）。
- 时长越长越好（爆量中位 99 秒）；转化率爆量档 1.76%。
- 订单少时 ROI 只当方向参考（客单 900 元左右，一单就摆 1.5～3）。
- 日报是当日数据；素材分析表（带播放率）只能选到 3 天前。

## 生产规矩（全是踩过或用户定过的）

- **视频最高 720p**，不跑 1080p。LibTV Seedance 720p 约 46 积分/秒。
- **开头默认 1.1 倍速**（1.2 偏快）。
- **出片必须逐句回听**：Seedance 会在两句之间自己多说含糊话。ASR 把「秋参」听成「秋深」是识别误差，不用改。
- **人设号家庭成员用真人参考 + 真实称呼**，不随手生成陌生面孔。人脸像不像交给用户判断。
- **场面画面要满、多、热闹**（货架堆满、身后一群人），不要空货架。夸张场景和数量，不夸张单根大小和效果。
- 季节措辞对上时令（10 月是秋参）。
- AI 段加「画面含AI生成内容」小字。千川红线：极限词、人物证言、功效暗示必拒；同句别条已过审就出技术变体重传（`../make_variants.sh`）。
- 配空镜：口播是骨架，说到看得见的东西（卖点、吃法、源头）才插空镜，情绪、人设、喊单留脸；单镜 ≤2.2 秒，包装/礼盒镜头限量。
- 去停顿：成片前一律压掉 >0.45 秒空白。
- 每批成片集中放一个文件夹并传网盘，别散在 run 目录。剪映草稿交付用 `../deliver.py`。
- 叫法：用 AI 重做号内爆款开头叫「重制」，不叫「重置」。

## 选开头的顺序

1. 先看台账：哪个家族被放量了 → 做它的变体（换人、换场景、换道具；模板寿命按具体版本算，不按模板算）。
2. 再看用户在素材库标的「要复刻」里还没做的。
3. 再从三张榜里挑跨品类、≥5 条、没用过、能改成本产品的组。**桥段榜、转化榜也能换**（换中段、换结尾），每批只换一个变量。
4. 号内消耗高的老爆款，开头用 AI 重制（场景更丰富、道具更夸张）。

榜单只是假设：开头榜第 1、2 组（囤不囤、价格挂错）做出来 0 单。最终看投放数据。
