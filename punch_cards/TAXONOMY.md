# 例文卡分类法 TAXONOMY(09-05,吸收铁甲千川课后定版)

> 原则:分类服务检索,不服务教学。每条轴都对应一个真实的检索/决策动作。
> 词表来自「铁甲·千川全域素材破局课 2026.3」精读 + 我们三条片的实证。
> 归不进词表的好片子**不硬塞,沉淀新类**(分类从数据里长出来,课程只提供先验)。

## 轴1:钩子类型 hook_type(B 模式改写的第一决策点,14 类)

课程核心纪律:**卖点痛点不变,开头永远在变;开头一变=触达人群变=新素材**。
所以钩子类型是例文卡最重要的检索轴——选钩子类型=选人群入口。

| 词 | 判别特征(看前3秒) | 适用/备注 |
|---|---|---|
| 点名受众 | 直接喊人群(年龄/职业/体型/消费层级/场景) | 人群明确的产品首选;"80后""外卖员""矮个子" |
| 痛点供给 | 罗列不方便/难受场景(可单痛点/多痛点叠加) | ★痛点必须讲后果链(慢→迟到),只讲现象是残次品 |
| 身份推荐 | "我作为XX/我堂哥跑长途/我表姐是老师" | 身份真假不重要;达人素材最常见形态 |
| 对话冲突 | 第一帧两人对峙/吵架/找茬,产品已在画面 | 吃瓜人群;冲突中解答质疑点 |
| 提出疑问 | 问句开头(质疑/矛盾/数据/预测) | 反向质疑(是不是智商税)最强 |
| 开箱评测 | 拆包裹仪式感/神秘感 | 大件必用;分发货开箱/对比开箱 |
| 产地探访 | 工厂/码头/流水线/凌晨仓库 | 源头=便宜的心理;溯源信任 |
| 实验 | 砸/泡/烧/对比测试把卖点变可感知 | 金鱼洗洁精法;功效型避开直白演示 |
| 情绪共鸣 | 先渲染坏情绪不讲参数 | 焦虑/自卑/尴尬/压力;好情绪没痛点,坏情绪才有 |
| 效果前置 | 第一帧直接是用完的效果(0→1省略) | 多数人不想看过程只想知道有没有效 |
| 对比呈现 | 用/不用、前/后、线上/线下并置 | 注意卡审:别直接擦脏鞋,用两双鞋让人自己关联 |
| 悬念好奇 | 反常行为/话说一半/埋梗不解释 | 梗不需要解答 |
| 正话反说 | 表面在喷实际在夸(喷的点恰好是卖点) | 迭代法:同行爆款喂 AI"一样意思反过来讲" |
| 蹭热点 | 提节日/时事/赛事,迅速拐产品 | 固定节日提前半月拍;热点只带一句不展开 |

组合允许(课里就是组合用的),记主类型。

## 轴2:片型 type(主体框架,课程五框架 + 我们的细分)

课程五框架(画面 C 位是什么):
- `kou` 口播(人对镜头讲;含场景切换口播)
- `product` 产品为主体(美食特写等;配人物背景板/吃相更好)
- `scene` 场景为主体(家居空间类必拍;可做跳跃式场景=非正常场景放大痛点再拉回)
- `action` 动作夸张放大(视频里人的期待值天然降半档,现实夸张=视频正常)
- `bgm` 无口播,靠 BGM+画面

我们的细分(保留,映射到五框架):
`tutorial_demo` 教程演示(→kou+action)/ `talking_head` 独白种草(→kou)/
`product_showcase` 好物展示(→product)/ `street_interview` 街采(→kou)/
`group_skit` 群戏剧情(→action)/ `efficacy_compare` 功效对比(→action+实验钩)/
`single_take_proof` 一镜到底证据(→action)

## 轴3:段功能 beat_function(自有词表,对齐课程四段论)

钩子(前3-5s,决定划走)| 痛点(前置中段,第一痛点带后果链)| 机制讲解| 卖点证明
| 价格机制| 信任背书| CTA| 过渡
——后置中段=卖点证明/机制讲解的填充,结尾不重要(95%的人看不到)。

## 轴4:素材段位 tier(课程 A 卷)

`hard_ad` 纯硬广(讲大卖点天经地义,但只能打动纯刚需、千展贵)/
`content` 内容素材(硬广+钩子+可视化,**我们的主战场**)/
`persona` 人设素材(先有身份再卖货,难抄袭跑量率高,钻石级)

## 轴5:转化目标 goal(09-06 加,带货 vs 直播引流的结构性分叉)

`direct_sale` 直接带货(CTA=点左下角进商品页,价格机制=商品机制)
`live_funnel` 直播引流(CTA=进直播间,话术带时效性和憋单,价格往往不说死)
——两类的钩子/片型/痛点写法通用,**CTA 段和价格机制段的写法分叉**,检索时同 goal 优先。

## 轴6:人群/类目/价格带(不变)

audience(购买者≠使用者时记购买者:"子女买给老人")/ category / price_band。

## 课程给的、我们卡里没有的新字段

- `hook_type`(轴1)
- `emotion_chain`:坏情绪→好情绪的转化链一句话(先喊痛点勾坏情绪,再给卖点解决好情绪)
- `visual_hook`:卖点可视化手法(实验/对比/夸张动作/场景映射…)

## B 模式本地化的新纪律(09-05 起,替代"每段平均用力改词")

1. **钩子段重写**:按目标人群选 hook_type,从库里捞同类钩子例文仿写
2. **痛点/卖点段最小改动**:只换产品名/数字/机制,结构句式照抄原片或同类例文
3. **CTA 保留**:原片的行动号召通常直接可用
4. **变体迭代换钩子类型,不换台词细节**(A 爆了别出 A1~A5——GMV 赛马会压死同类)
5. 可选成对策略:降智直给版 + 升智反踩版各一条,抓两拨人
